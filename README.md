# pressing

Counter-press report generator. One command turns a tracking or event file into a match report a coach
would actually hand out: pitch-control heatmaps at every possession loss, a five-second recovery metric
per player and per phase of the pitch, and a side-by-side team comparison. Season mode ranks players
league-wide and joins market values.

**Status: in development.** The package skeleton, canonical schemas and CLI are in place; the analytics
are not implemented yet.

## Install

Requires Python 3.11 or 3.12 and [uv](https://docs.astral.sh/uv/).

```sh
uv venv --python 3.11
uv sync --all-extras
uv run pressing --help
```
